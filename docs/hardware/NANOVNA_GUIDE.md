# NanoVNA-H4 — Посібник для CoinTrace

**Прилад:** NanoVNA-H4 (50 Ω, 50 kHz – 1500 MHz)  
**Об'єкт вимірювань:** MIKROE-3240 (LDC1101 Click Board), PCB-котушка S1 + C4=330 pF  
**Апаратні дані (hw-верифіковано 2026-03-23):**
- fSENSOR = 909.2 kHz
- L ≈ 92.8 μH (розрахункове)
- C4 = 330 pF (по схемі)
- Діаметр котушки S1 = 24 мм, текстоліт 1.5 мм

**Версія документу:** 1.0.0 (2026-03-23)  
**Перехресні посилання:** `docs/hardware/HW_VERIFICATION_JOURNAL.md`, `docs/architecture/LDC1101_CLKIN_INTEGRATION.md`

## 1. Підготовка та підключення

### Калібрування (ОБОВ'ЯЗКОВО перед кожним сеансом)

1. Підключити SMA-кабель до **CH0 (PORT 1)**
2. NanoVNA → Menu → **Calibrate** → OPEN → SHORT → LOAD (50 Ω) → Done
3. Зберегти як Slot 0: Menu → Save → 0
4. Перевірити: Smith chart CH0 має показувати точку праворуч (OPEN) — без кабелю

> ⚠️ Кожного разу при зміні кабелю або адаптера — перекалібрувати.

### Точки підключення на MIKROE-3240

**Пристрій ВИМКНЕНИЙ** для сценаріїв A–D.

```
MIKROE-3240 (вид зверху):
┌─────────────────────────────┐
│  mikroBUS роз'єм            │
│  (ліва сторона плати)       │
├─────────────────────────────┤
│                             │
│  LDC1101 (U1)               │
│     INA (pin 7) ──── C4 ───┤── S1 (котушка)
│     INB (pin 6) ──── C4 ───┘
│                             │
│  JP1 (jumper, внизу)        │
└─────────────────────────────┘
```

**Щупи NanoVNA CH0:** підключити до ніжок **C4** (конденсатор 330 pF, біля котушки).  
Альтернативно: прямо до through-hole падів котушки S1 між INA і INB.

**Практичний спосіб:** крокодили до INA/INB через коротку перемичку (< 5 мм провід).

## 2. Сценарій A — Верифікація fSENSOR

**Мета:** незалежно підтвердити fSENSOR = 909.2 kHz, виміряного LDC1101.

### Налаштування NanoVNA

| Параметр | Значення |
|---|---|
| Режим | S11 (одна крива, CH0) |
| Старт | 500 kHz |
| Стоп | 1500 kHz |
| Кількість точок | 201 |
| Display | |Z| (модуль імпедансу) |

**Кроки:**
1. Підключити CH0 до C4/INA-INB (пристрій вимкнений)
2. Setup → Start: 500 kHz → Stop: 1500 kHz
3. Перейти на Display → |Z|
4. Знайти мінімум |Z| — це і є fSENSOR (LC-резонанс = мінімальний імпеданс у послідовному резонансі)

> **Примітка щодо інтерпретації:**  
> Ідеальний LC-паралельний резонанс = максимум |Z|.  
> Послідовний резонанс (паразитна ємність кабелю + L) = мінімум |Z|.  
> NanoVNA зазвичай бачить **мінімум** через малий послідовний ESP конденсатора.  
> Якщо бачиш максимум — переключи Display на Phase і знайди нуль фази.

### Очікуваний результат

```
|Z| мінімум: ~909 kHz ± 20 kHz

Якщо співпадає — fSENSOR підтверджено незалежно ✅
```

**Порогові значення:**
- `|909 kHz − f_NanoVNA| < 50 kHz` → повна кореляція ✅
- `50–100 kHz відхилення` → прийнятно (паразити щупів, температура)
- `> 100 kHz відхилення` → перевір підключення, паразитна індуктивність кабелю

### Скріншот Smith chart

Додатково: Display → Smith chart.  
При резонансі LC-контур перетинає вісь **Re(Z)** — точка перетину = fSENSOR.  
Запиши координати (fMHz, Re(Z) в Ω) — це буде еквівалентний послідовний опір котушки (ESR).

## 3. Сценарій B — Q-фактор котушки

**Мета:** виміряти Q-фактор. LDC1101 потребує Q > 15, оптимально Q > 40.

### Метод (-3 dB bandwidth)

1. Виконати Сценарій A (отримати fSENSOR на графіку |Z|)
2. Знайти мінімум |Z| = Zmin при f0 = 909 kHz
3. Знайти дві частоти де |Z| = Zmin × √2 (тобто +3 dB відносно мінімуму)
4. Обчислити:

$$Q = \frac{f_0}{f_2 - f_1}$$

**Приклад:**
- f0 = 909 kHz, |Z|min = 8 Ω
- |Z| = 8 × 1.414 = 11.3 Ω досягається при f1 = 885 kHz і f2 = 933 kHz
- Q = 909 / (933 − 885) = 909 / 48 ≈ **18.9**

### Маркери на NanoVNA

Menu → Marker → Marker 1 → ввести 909 кHz (або найти мінімум через пошук)  
Marker 2 та Marker 3 встановити на -3dB точки вручну через пересування пальцем.

### Класифікація результату

| Q | Статус | Наслідки для CoinTrace |
|---|---|---|
| > 60 | Відмінно | Максимальна чутливість, стабільний RP_DATA |
| 30–60 | Добре | Впевнена робота при всіх metal types |
| 15–30 | Прийнятно | Працює, але менша різниця між матеріалами |
| < 15 | Проблема | LDC1101 може давати нестабільні RP/L читання |
| < 5 | Критично | Переглянути RP_SET, перевірити пайку |

## 4. Сценарій C — Пряме вимірювання L та C4

**Мета:** незалежно виміряти L ≈ 92.8 μH і перевірити C4 = 330 pF.

### 4a. Вимірювання L (нижче резонансу)

**Sweep:** 100 kHz – 500 kHz (далеко нижче резонансу 909 kHz)  
При f << fSENSOR: C4 практично розімкнений ($X_C$ >> $X_L$), бачимо чисту L.

**Display:** Phase (фаза має бути +90° для чистої індуктивності)

NanoVNA Marker при 200 kHz покаже X (реактивний опір):

$$L = \frac{X_L}{2\pi f} = \frac{X_{marker}}{2\pi \times 200000}$$

**Очікування:** L ≈ **92–95 μH**

### 4b. Вимірювання C4 (вище резонансу)

**Sweep:** 2 MHz – 10 MHz (вище резонансу)  
При f >> fSENSOR: L практично замкнений ($X_L$ >> $X_C$), бачимо чистий C.  

**Display:** Phase (має бути -90° для чистої ємності)

NanoVNA Marker при 5 MHz покаже X:

$$C = \frac{1}{2\pi f \cdot |X_C|} = \frac{1}{2\pi \times 5000000 \times |X_{marker}|}$$

**Очікування:** C ≈ **290–370 pF** (±10% від 330 pF)

### Cross-validation формула

Якщо виміряли L і С — розрахуй незалежну fSENSOR:

$$f_{calc} = \frac{1}{2\pi\sqrt{L \cdot C}}$$

Якщо $|f_{calc} - 909.2\ kHz| < 5\%$ — повна незалежна верифікація ✅

## 5. Сценарій D — Реакція на монети

**Мета:** фізично зрозуміти fingerprint ПЕРЕД реалізацією C-2 state machine.  

**Пристрій вимкнений.** NanoVNA підключений до INA/INB.

### Процедура

1. Виконати Сценарій A (baseline без монети)
2. Зберегти trace: Memory → Store Trace → CH0 (синя лінія = baseline)
3. Покласти монету плоско на котушку (0 мм — максимальний ефект)
4. Спостерігати зміщення fSENSOR

**Таблиця для заповнення:**

| Монета | Матеріал | fSENSOR з монетою | Δf відносно baseline | Напрямок |
|---|---|---|---|---|
| — (baseline) | — | 909.2 kHz | 0 | baseline |
| UAH 1 | сталь+нікель | _виміряти_ | _Δf_ | ↑ або ↓ |
| UAH 2 | сталь+нікель | _виміряти_ | _Δf_ | ↑ або ↓ |
| UAH 5 | сталь+нікель | _виміряти_ | _Δf_ | ↑ або ↓ |
| AG монета | срібло | _виміряти_ | _Δf_ | ↑ або ↓ |

### Фізична інтерпретація

**fSENSOR зростає** (Δf > 0):  
Монета з **високою провідністю** (срібло, алюміній, мідь) — eddy currents "виштовхують" магнітне поле, **зменшують ефективну L** → f зростає.

**fSENSOR падає** (Δf < 0):  
Монета з **феромагнетиком** (нікелева сталь, залізо) — підвищує μr → **збільшує L** → f падає.  
Саме цей ефект визначає RP_DATA в LDC1101.

### Відстань 1 мм vs 3 мм

Повтори для кожної монети при двох відстанях (підкласти текстоліт 1 мм і 3 мм товщиною):  
Це покаже **профіль чутливості** — наскільки різко спадає сигнал з відстанню.  
LDC1101 C-2 state machine записуватиме саме ці 3 позиції (0, 1, 3 мм).

## 6. Сценарій E — LEDC гармоніки на G4

**Мета:** перевірити що меандр 16 MHz на G4 не створює паразит у смузі котушки.

**Пристрій УВІМКНЕНИЙ** (прошитий firmware зі Step4i).

### Підключення

```
G4 (EXT Pin 3) ──── 100 Ω резистор ──── SMA ──── NanoVNA CH0
GND ESP32 ──────────────────────────────────────── NanoVNA GND
```

> ⚠️ Резистор 100 Ω обов'язковий — без нього NanoVNA навантажить LEDC і може
> спотворити результат (або пошкодити GPIO при нестандартних умовах).

### Налаштування

| Параметр | Значення |
|---|---|
| Режим | S11 або просто |Z| sweep |
| Старт | 10 MHz |
| Стоп | 200 MHz |
| Display | logmag (логарифмічна амплітуда) |

### Очікований спектр

```
Частота    | Рівень    | Це
───────────┼───────────┼──────────────────────────────
16 MHz     | висока    | основна гармоніка LEDC
48 MHz     | -10 dB    | 3-я гармоніка (1/3 від основної)
80 MHz     | -14 dB    | 5-та гармоніка
112 MHz    | -17 dB    | 7-ма гармоніка
...        | спадають  | непарні гармоніки меандру
```

### Критерій прийнятності

Гармоніки на **909 kHz ± 500 kHz** (смуга котушки) — **не повинні бути присутні:**  
Найближча гармоніка 16 MHz >> 909 kHz → проблем немає ✅

Якщо бачиш спайк близько 900 kHz на графіку → потрібен ferrite bead на G4.

## 8. Що робити якщо результати розходяться

### fSENSOR (NanoVNA) відрізняється від 909.2 kHz на > 5%

**Можливі причини:**
1. Паразитна індуктивність щупів/кабелю (+5–20 nH → зміщує f до 950–980 kHz)
   - Рішення: коротші з'єднання, перекалад
2. Температурний дрейф котушки (PCB-L залежить від температури)
   - Рішення: виміряти при ~25°C, порівняти з умовами boot-лога
3. LDC1101 **навантажує** котушку при увімкненому пристрої
   - Рішення: вимірювати при **вимкненому** пристрої (сценарії A–D)

### Q < 15

**Можливі причини:**
1. Погання пайка котушки (окислення, холодна пайка) → збільшується ESR
2. Земляна петля між NanoVNA і платою
3. MIKROE-3240 без mikroBUS роз'єму у повітрі — нормально для Q 15–30

### L значно відрізняється від 92.8 μH

- L < 50 μH → можлива паразитна ємність кабелю впливає на вимір; спробувати sweep ще нижче (50–100 kHz)
- L > 150 μH → C4 впливає на вимір; перевірити що C4 не відпаяний

### Монета не змінює fSENSOR

- Монета занадто далеко → покласти впритул (0 мм)
- Монета занадто мала → спробувати більшу
- Перевірити підключення NanoVNA
